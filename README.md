# Newsk

> tir labs News initiative: accessible tech for those who pursue journalism with limited resources.

Newsk is the core project. Small machines, big coverage — scrapers, datasets, and a
lightweight OS flavor for newsrooms that cannot afford a newsroom.

- **Website**: [Newsk.dev](https://newsk.dev) — datasets, OS, program news.
- **Datasets**: [NewskList](https://github.com/labsbytir/NewskList) + [NewskData](https://github.com/labsbytir/NewskData) — 28,384 curated news sources.
- **OS**: Newsk Lite (headless) + Newsk Full (Openbox desktop) — Wolfi-based, built with melange/apko.
- **Experiments**: [GoNewsk](https://github.com/labsbytir/GoNewsk) (headless scraper), [EmDash](https://github.com/labsbytir/EmDash) (editor fork).
